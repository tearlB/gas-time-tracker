# 予定は期間で押さえ、実績だけを日に載せる

2026-10-14 に、週予定を「日ごとの予定時間の割り当て」から「開始日〜終了日の期間（ガントのバー）」へ切り替えた。旧方式は [weekly-forecast-algorithm.md](weekly-forecast-algorithm.md) に残している。

## 予定が持つもの

| 項目 | 意味 |
| --- | --- |
| 開始日・終了日 | その予定に取り組むつもりの期間。週をまたいでよい |
| 予定工数 | 期間全体での合計時間。予実の比較や月の残り工数に使う |

「1日の上限」「日別の予定」は使わない。シートの列（`1日上限`・`日別予定JSON`）は既存データのため残すが、画面からは編集しない。

予定の行は、これまでどおり登録した週（`期間キー`）に保存する。表示する週は日付で決める。

## 期間未定の予定

予定ダイアログで開始日・終了日を両方空のまま登録すると「期間未定」になる（一般的なガントチャートと同じく、日付は必須にしない）。片方だけ入れた場合は保存しない。シートでは開始日を空、終了日の列を `未定` にする（日付が空の旧データと区別するため）。

- 「予定を追加」ボタンからは日付を空で開く。日付の「＋」から開いたときは、押した日からその週の金曜までを入れておく。
- 入れた日付は「日付を消す（期間未定にする）」で空に戻せる。
- 日付が空の旧データを編集で開いたときは、登録した週の月〜金を入れて開く（そのまま保存しても期間未定に変わらない）。

- 週の画面ではバーを出さず、名前の欄に「期間未定」と出す。実績はその日のセルに載せる。
- 完了するまで、登録した週以降の画面に出し続ける。完了したら、登録した週と実績がある週にだけ出す。
- 期限がないので「前倒し」「期限超過」「期限切れ」にはならない。予定工数の超過だけ注意にする。
- 実績画面の候補では「今週」に「期間未定」と添えて出す。

## 終了日が空の旧データ

- 開始日が空なら、登録した週の月曜を開始日とみなす。
- 終了日が空なら、開始日の週の金曜（開始日が土日ならその日）を終了日とみなす。
- 画面で予定を編集して保存すると、開始日・終了日が書き込まれる。

## 週の画面に出す予定

次のどれかに当てはまる予定を出す。

1. 期間がその週にかかる（完了していても出す）。
2. その週に実績がある（前倒し・期限後の作業）。
3. 未完了のまま終了日を過ぎている。今日を含む週とそれより先の週にだけ「期限切れ」として出す。まだ期限前の予定は、終了日の週より先には出さない。
   - 終了日が空の旧データは、以前の持ち越しと同じく、実績がある予定だけを残す。

サーバー（`selectWeeklyPlansForDailySuggestions`）は、前16週と先16週の予定から、期間がかかる予定・その週に実績がある予定・未完了の前の週の予定を返す。画面（`planVisibleInWeek`）が上のルールで最終的に出すかを決める。

## 1日分のセル

- 期間内の日はバーを引き、その日の実績だけを数字で載せる。
- 開始日より前の実績は「前倒し」（橙）、終了日より後の実績は「超過」（赤）としてバーの外に出す。
- 期間が週の外へ続くときは、週の端に「◀ 10/8〜」「〜10/24 ▶」と続きを出す。
- 期限切れの予定は、期間内のバーを赤くする。

## 名前の欄

- 期間（例：`10/14〜10/22`）
- 「前倒し 10/13〜」「期限超過 〜10/20」「期限切れ」「工数超過」のバッジ
- 状態（未着手・進行中・完了）。注意（赤）にするのは、期限切れ・終了日より後の実績・予定工数の超過のとき。前倒しだけでは注意にしない。

終了日が空の旧データは、同じ名前の古い実績も通算されているため、登録した週より前の実績は前倒しに数えない。

## 日付の見出し

その日の実績合計と稼働時間（`実績 6.5 / 8h`）を出す。押すと稼働時間を変えられる。日ごとの予定時間がないので「空き」は出さない。

## 実績画面

- 「計画消化」は「稼働消化」（本日の実績 ÷ その日の稼働時間）に変えた。
- 「週の課題から選ぶ」は、この週の終わりまでに始まる予定を「今週」、それより後に始まる予定（4週先まで）を「これから」に分ける。
- 候補には期間を出し、開始日より前なら「前倒し」、終了日を過ぎていれば「期限超過」と添える。

## 月ビュー（見るだけ）

表示の切り替え（日・週・月）の「月」で、Backlog のガントチャートのように1か月を見渡す。

- 予定はプロジェクトごとにまとめる（プロジェクト一覧の順、未設定は最後）。グループは開閉できる。
- 列は1日〜末日。期間をバー、日ごとの実績を数字で出す。前倒し・期限超過の実績は橙・赤。月の外へ続く予定は端に ◀ ▶。
- 出す予定のルールは週の画面と同じ（`planVisibleInWeek` を月の範囲で使う）。
- サーバー（`loadPlanningMonthGantt`）は、月にかかる各週を週の画面と同じ集計（`calculateBudgetSummary`）で計算し、予定IDでまとめて返す。
- 絞り込み：予定名、プロジェクト（未設定も選べる）、状態（未完了・完了）、予定日からずれている予定だけ（前倒し・期限超過・期限切れ・工数超過）。検索語以外はこのブラウザに覚える。
- 編集はしない。予定を押すとその予定がある週の画面へ移り、行を強調する。日付を押すとその日の実績を開く。

## 他の週に登録した予定を編集したとき

この週の画面で、前の週（または先の週）に登録した予定を編集すると、登録した週の行へ書き戻す（`saveContinuedOrigins`）。内容が変わっていない週には書き込まない。この週の画面で足したサブタスクも、登録した週へ残す。
