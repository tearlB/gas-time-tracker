      保存の記録を確認しています…

      データを点検
      変更履歴から戻す手順
      1. アプリでの保存を止めます（このあと日次や予定を編集しないでください）。
      2. 上の「年次管理ファイルを開く」でスプレッドシートを開きます。
      3. メニューの「ファイル → 変更履歴 → 変更履歴を表示」を開きます（Ctrl+Alt+Shift+H）。
      4. 案内に出ている「最後に正常に保存した時刻」と同じか、それより前の版を選びます。
      5. 「この版を復元」を押します。今の状態も変更履歴に残るので、あとから戻し直せます。
      6. アプリに戻り、上の「シートと同期」を押して読み直します。

        形式変更のバックアップ

        連携と同期方法

        Google Tasks連携を有効にするオフの間は手動同期・自動同期とも実行しません。
        自動同期するオンにすると、アプリ起動時と日次・予定・プロジェクトの保存後に同期します。アプリを閉じている間の定期同期は行いません。

        同期先と対象

        同期するのは予定の課題だけです。日次だけの作業とカレンダー実績は含みません。完了した予定は Google Tasks でも完了になり、未完了の一覧から消えます。対象月は、プロジェクト画面なら表示中の月、それ以外なら今月です。

        同期状況

        連携・同期先の変更は、設定を保存すると反映されます。

        シートの変更を自動で読み直すAIや人がスプレッドシートを直接書き換えたとき、アプリを開いている間は1分ごとと、タブに戻ったときに確かめて読み直します。オフにすると「保存先・データ」の「シートと同期」を押したときだけ読み直します。

        予定と実績の完了状態を同期する標準はオフです。オフでは、それぞれで完了・未完了を選べます。オンにすると、実績の完了・取り消しを予定にも反映します。切り替えると本人の設定に保存されます。
